=== SLIDE 2 ===
Software
•ซอฟต์แวร์ (Software) คือ ชุดคำสั่งหรือโปรแกรมที่ควบคุมการทำงานของ
คอมพิวเตอร์และอุปกรณ์อิเล็กทรอนิกส์ต่างๆ 
•แบ่งออกเป็น 2 ประเภทหลัก คือ
1. ซอฟต์แวร์ระบบ (System Software) 
2. ซอฟต์แวร์ประยุกต์ (Application Software)
2

=== SLIDE 3 ===
3
Software
1. ซอฟแวร์ระบบ (Systems Software) คือ ชุดของโปรแกรมที่ประสานให้ฮาร์ดแวร์และโปรแกรม
ให้ทำงานร่วมกันได้ ทำหน้าที่ควบคุมการทำงานพื้นฐานของคอมพิวเตอร์และอุปกรณ์ต่างๆ รวมถึงการ
จัดการทรัพยากรของระบบ เช่น ระบบปฏิบัติการ (Operating System) DOS, UNIX, WINDOWS, 
OS, Linux
2. ซอฟแวร์ประยุกต์ (Application Software) คือ ซอฟต์แวร์หรือโปรแกรมที่ทำให้คอมพิวเตอร์
ทำงานต่าง ๆ ตามที่ผู้ใช้ต้องการ เพื่อทำงานเฉพาะด้าน
เช่น 1. โปรแกรมประมวลผลคํา 2. โปรแกรมตารางคํานวณ 3. โปรแกรมนําเสนอ 4. โปรแกรมจัดการ
ฐานข้อมูล 5. โปรแกรม Antivirus 6. ซอฟต์แวร์สําหรับการจัดการภาพกราฟิก 7. ซอฟต์แวร์สร้าง
เว็บไซต์ 8. ซอฟต์แวร์ตัดต่อเสียงและวิดีโอ

1. Operating Systems ระบบปฏิบัติการ
• คือ Set of programs that controls computer hardware and acts as an 
interface with application programs
ชุดโปรแกรมที่ควบคุมฮาร์ดแวร์คอมพิวเตอร์ และทำหน้าที่เป็นส่วนติดต่อ
ประสานกับโปรแกรมแอปพลิเคชัน
• Kernel
• Ties all components of the OS together and regulates other programs 
เป็นแก่น ซึ่งเป็นส่วนสำคัญของระบบระบบปฏิบัติการ ช่วยในการติดต่อกับ
ส่วนประกอบทั้งหมดของระบบปฏิบัติการเข้าด้วยกันและควบคุมโปรแกรมอื่น ๆ

Middleware
• Middleware: Software that allows different systems to communicate 
and exchange data ซอฟต์แวร์ที่ช่วยให้ระบบต่าง ๆ สามารถสื่อสารและ
แลกเปลี่ยนข้อมูลได้
• Can also be used as an interface between the Internet and older 
legacy systems สามารถใช้เป็นส่วนต่อประสานระหว่างอินเทอร์เน็ตและระบบ
เก่าได้
• Service-oriented architecture (SOA)
• Uses modular application services to allow users to interact with systems, 
and systems to interact with each other ใช้บริการแอปพลิเคชันแบบเป็นส่วน ๆ 
เพื่อให้ผู้ใช้สามารถโต้ตอบกับระบบและระบบเพื่อโต้ตอบซึ่งกันและกัน

ค าว่า Copyrights and Licenses
•Most software products are protected by law using copyright or 
licensing provisions
• In some cases, you are given unlimited use of software on one or 
two computers
• In other cases, you pay for your usage - if you use the software 
more, you pay more
•Some software now requires that you register or activate it 
before it can be fully used. ซอฟต์แวร์บางตัวต้องการให้ลงทะเบียน

ค าว่า Open-Source Software
•ซอฟต์แวร์ที่มีซอร์สโค้ดที่ทุกคนสามารถตรวจสอบ แก้ไข และปรับปรุงได้ 
•Software freely available to anyone in a form that can be easily 
modified
•More reliable and secure than commercial software
•Can contain hidden costs, particularly for user support or 
solving problems with the software

ค าว่า Shareware, Freeware 
•Freeware คือซอฟต์แวร์ที่ให้ใช้งานได้ฟรีโดยไม่มีค่าใช้จ่ายและไม่มีข้อจำกัด
เรื่องระยะเวลา ไม่สามารถแก้ไขซอร์สโค้ดได้
•Shareware เป็นซอฟต์แวร์ที่ให้ทดลองใช้ฟรีในช่วงเวลาจำกัด หรืออาจมี
ฟังก์ชันบางอย่างถูกจำกัดไว้ และเมื่อหมดระยะเวลาทดลองหรือต้องการใช้
ฟังก์ชันที่ถูกจำกัด จะต้องเสียค่าใช้จ่ายเพื่อซื้อตัวเต็ม ไม่สามารถแก้ไขซอร์
สโค้ดได้

Software Upgrades ท าไมต้อง Upgrade SW
•Software companies revise their programs and sell new versions 
periodically
•Revised software may or may not offer any major additional 
capabilities
•Revised software can contain bugs or errors
•Software upgrades usually cost much less than the original 
purchase price
